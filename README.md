# Sistema de Control de Ventas Básico

## 📌 Descripción

Este proyecto es un sistema sencillo de control de ventas desarrollado en Python. El sistema permite registrar productos, cantidades y precios, y calcular el total de la venta. Es ideal como base para desarrollar un sistema de ventas más completo, como una tienda, minimarket o quiosco.

## 🛠 Tecnologías utilizadas

- **Python 3**
- Archivo `.py` ejecutable en consola
- Git y GitHub para control de versiones

## 📁 Estructura del proyecto


## 🚀 Funcionalidades

- Agregar productos con nombre, cantidad y precio.
- Calcular el subtotal y total de cada venta.
- Mostrar un resumen de todos los productos vendidos.
- Código modular para futuras mejoras (como interfaz gráfica o base de datos).
